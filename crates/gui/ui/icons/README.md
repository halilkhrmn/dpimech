Icons from [Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons)
(`@fluentui/svg-icons` 1.1.343, 20 px regular), © Microsoft Corporation, MIT License.
They are embedded into the binary, so every OS shows the same icons (the Segoe Fluent Icons
font used before exists only on Windows 11). File name → original icon:
home → home, lab → beaker, engines → arrow_download, logs → document_text,
settings → settings, add → add, back → arrow_left, delete → delete, warning → warning,
shield → shield_checkmark, refresh → arrow_clockwise, info → info, done → checkmark_circle (filled).
`more.svg` (three dots) is drawn for this project in the same style.
